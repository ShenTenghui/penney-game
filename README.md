# 三枚硬币

一个和朋友玩 Penney's Game 的小网页：两人先后选定三枚硬币的组合，逐次抛掷，先连续出现的一方获胜。

## 玩法

1. P1 先选，P2 再选。八种组合任选，两人的组合不能相同。
2. 点击「抛一次」，或开启「连续抛掷」。也可以抛真实硬币，再点「记录正 / 记录反」。
3. 每次结果按顺序保留。检查的是每一个相邻的三枚窗口，窗口可以重叠；例如 `正正正反` 中包含 `正正反`。
4. 首个组合出现即结束，三条获胜记录会高亮。点「新一轮」清空记录，重新选择。

页面下方折叠着后手策略和双方当前组合的精确胜率，可以先玩，再展开看。

## 运行

下载后直接双击 `dist/index.html`。无需安装依赖或注册账号，也可以在项目目录运行：

```sh
python -m http.server 8000 --directory dist
```

然后打开 <http://localhost:8000>。

当前轮次仅保存在当前浏览器的 `localStorage`，刷新可以继续。清理浏览器数据会清除记录；浏览器拒绝本地存储时，页面仍可使用，但刷新后不会保留。自动抛掷不会跨刷新恢复，切换到后台标签页也会暂停。

## 实现

- 无框架，HTML、CSS 和普通 JavaScript；既支持静态托管，也支持本地文件打开。
- 使用浏览器 `crypto.getRandomValues` 取独立的公平硬币结果，自动抛掷与手动抛掷使用同一套判胜规则。
- `dist/core.js` 独立实现组合校验、滑动窗口判胜、存档校验和精确概率，同时兼容浏览器与 Node。
- 从第一枚开始保留完整序列，不在产生赢家后追加结果；本地存档恢复时重新核对首次命中位置。

理论概率使用组合间前后缀重合权重。测试将所有 56 对不同组合的概率与独立的吸收马尔可夫链求解对照，并验证八种最优应对、重叠匹配、胜后锁定和异常存档。

```sh
npm test
```

测试使用 Node.js 22 或更高版本的内置测试器，无第三方依赖。GitHub Actions 在 Node.js 22、24 上运行。

## 关于这个游戏

三枚组合的边际概率相同，两个组合「谁先出现」的概率却可能不同，这也是这个游戏好玩的地方。[数学分析与延伸阅读](https://arxiv.org/abs/1904.09888)。
